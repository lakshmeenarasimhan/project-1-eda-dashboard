# Bangalore Restaurant Analysis Dashboard

An interactive EDA dashboard built on 41,000+ Zomato Bangalore restaurants.

## Live Demo
[Click here to view the dashboard](https://project-1-eda-dashboard-bodmkh3ajh93zzxuntesvp.streamlit.app/)

## Key Finding
Cost and rating have only a **0.38 correlation** — meaning expensive 
restaurants are NOT guaranteed to be better rated!

## Tech Stack
- Python, Pandas, NumPy
- Plotly, Streamlit
- Git, GitHub

## How to Run Locally
```bash
pip install -r requirements.txt
streamlit run app/app.py
```

## Dataset
Zomato Bangalore Restaurants — Kaggle
